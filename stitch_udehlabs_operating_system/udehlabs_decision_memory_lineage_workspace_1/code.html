pending_actions PROPOSED ADR-108

Migration to Modular Monolith

subject Context & Reason

The current microservices architecture for the Billing domain has introduced unacceptable network latency between the invoice-service and ledger-service, averaging ~120ms during P99 load.

We propose consolidating these tightly coupled domains into a single deployment unit (Modular Monolith) while maintaining strict logical boundaries via bounded contexts in the codebase.
