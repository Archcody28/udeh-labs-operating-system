Execute AI Agent

Synchronously executes a predefined AI agent with custom payload parameters, returning the deterministic output.

POST https://api.udehlabs.com/v1/agents/execute

lock Authentication

Requires a valid Bearer token in the Authorization header.

Authorization: Bearer <YOUR_API_KEY>

Request Body Schema

PROPERTY TYPE DESCRIPTION
agent_id* string The unique identifier of the configured agent to execute.
payload* object Key-value pairs matching the agent's expected input schema.
stream boolean If true, returns a Server-Sent Events stream instead of JSON.
Default: false
temperature number Overrides the agent's default temperature setting (0.0 to 2.0).
