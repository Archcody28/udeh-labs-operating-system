Implementing Multi-Tenant MFA

STATUS Requires Human Review
description STRATEGIC_OVERVIEW

Objective

Migrate existing single-tenant authentication flows to a multi-tenant aware architecture supporting localized MFA policies (TOTP, WebAuthn) per tenant organization while maintaining backwards compatibility for legacy API clients.

Strategy

  • Introduce `tenant_id` context to auth middleware.
  • Abstract MFA validation into pluggable strategy pattern.
  • Phased rollout behind feature flags (`ff_multi_tenant_mfa`).
  • Data migration script for existing user MFA secrets.
